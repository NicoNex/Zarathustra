# Base (sub-project 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static ARM binary, `zarathustra-probe`, launched from KUAL on the Paperwhite 5. It draws a test pattern, tracks touches with fast refreshes, does a hardware swipe page turn, and sets brightness and warmth. The same code runs in a desktop emulator window.

**Architecture:** Two crates. `zarathustra-device` holds the `Device` trait, pure gray8 canvas ops, MTK ioctls, MT-B touch decoding, sysfs light/battery, and an emulator backend behind a `emulator` feature. `zarathustra` (bin) holds the probe. Fully static `armv7-unknown-linux-musleabihf` build linked with `rust-lld`, so there is no glibc coupling to the Kindle firmware or a future distro.

**Tech Stack:** Rust 2021, `libc` (ioctl/mmap/epoll), `minifb` (emulator only), `anyhow` (bin).

**Device facts** (from KOReader sources on the device, `koreader/ffi/mxcfb_kindle_h.lua`, `framebuffer_mxcfb.lua`, `frontend/device/kindle/device.lua`):
- `MXCFB_SEND_UPDATE_MTK = 0x4060462E` (`_IOW('F', 0x2E, struct mxcfb_update_data_mtk)`, 96 bytes)
- `MXCFB_WAIT_FOR_UPDATE_COMPLETE = 0xC008462F` (`struct { u32 marker; u32 collision_test; }`)
- `MXCFB_SET_UPDATE_FLAGS_MTK = 0x4004463B`, arg `u32 = 0x8000_0000 | 1` enables fast mode (no silent REAGL promotion)
- MTK waveforms: DU=1, GC16=2, GL16=3, GLR16=4, A2=6. Flags: FORCE_MONOCHROME=2, ENABLE_SWIPE=0x10000. Swipe dirs: down 0, up 1, left 2, right 3. Steps 12 (stock). The driver crashes if the region is smaller than `steps` in w or h.
- `temp = TEMP_USE_AMBIENT (0x1000)`. `update_mode` 0 partial, 1 full. `hist_bw = DU`, `hist_gray = GC16`.
- Light: `/sys/class/backlight/fp9966-bl1/brightness` (white), `fp9966-bl0` (warm), `max_brightness` beside them.
- Battery: `/sys/class/power_supply/bd71827_bat/{capacity,status}`.
- Touch device path varies: find the `/dev/input/event*` that reports `ABS_MT_POSITION_X`.

### Task 2: Geometry + gray8 canvas (pure, TDD)

**Files:** `crates/zarathustra-device/src/geom.rs`, `canvas.rs`.

- `Rect { x, y, w, h }` with `intersect`, `union`, `is_empty`.
- `Canvas { width, height, stride, pixels: &mut [u8] }`: `fill(rect, gray)`, `blit` later.
- Tests: intersect disjoint → empty; union covers both; fill clips to bounds and respects stride padding.

### Task 3: Device trait + refresh model

**File:** `crates/zarathustra-device/src/lib.rs`.

```rust
pub enum Waveform { Full, Text, Fast, Mono }
pub struct Refresh { pub rect: Rect, pub waveform: Waveform, pub flash: bool, pub swipe: Option<Swipe> }
pub enum Swipe { Left, Right, Up, Down }
pub trait Framebuffer { fn canvas(&mut self) -> Canvas<'_>; fn refresh(&mut self, r: &Refresh) -> io::Result<u32>; fn wait(&mut self, marker: u32) -> io::Result<()>; }
pub trait Frontlight { fn brightness(&self) -> u8; fn set_brightness(&mut self, pct: u8) -> io::Result<()>; fn warmth(&self) -> Option<u8>; fn set_warmth(&mut self, pct: u8) -> io::Result<()>; }
```

Percent-based light API (0–100) mapped to each device's `max_brightness`.

### Task 4: MTK framebuffer backend (TDD on layout)

**File:** `crates/zarathustra-device/src/kindle/mtk.rs`.
- `#[repr(C)] UpdateDataMtk` matching the C struct. Tests: `size_of == 96`, and `iow(b'F', 0x2E, 96) == 0x4060462E`.
- `MtkFb::open("/dev/fb0")`: `FBIOGET_VSCREENINFO`/`FSCREENINFO`, mmap `smem_len`. Canvas = visible area with `line_length` stride.
- `refresh`: map Waveform → MTK mode (Full→GC16 + flash, Text→GL16 (fast mode on), Fast→DU+FORCE_MONOCHROME, Mono→A2). Swipe sets ENABLE_SWIPE + direction if `w,h ≥ 12`. Markers increment, skipping 0.

### Task 5: Touch input (MT protocol B decoder, TDD)

**File:** `crates/zarathustra-device/src/input.rs`.
- `MtDecoder` consumes `(type, code, value)` and emits `Touch { id, phase: Down|Move|Up, x, y }` on `SYN_REPORT`, tracking slots. Tests: single finger down/move/up; two fingers on separate slots; tracking id -1 → Up.
- `find_touch_device()`: scan `/dev/input/event*`, `EVIOCGBIT(EV_ABS)` has `ABS_MT_POSITION_X`. Read `EVIOCGABS` ranges to scale to screen coordinates, with an axis transform (swap/mirror) from the profile.

### Task 6: Sysfs light + battery (TDD with temp dir)

**File:** `crates/zarathustra-device/src/sysfs.rs`.
- `SysfsLight { white: PathBuf, warm: Option<PathBuf> }`: pct ↔ raw via `max_brightness`, rounding to nearest. Test with a temp dir and fake files.
- `battery(capacity_path, status_path) -> Battery { percent, charging }`.

### Task 7: Kindle device assembly + emulator backend

**Files:** `crates/zarathustra-device/src/kindle/mod.rs`, `src/emulator.rs` (feature `emulator`, `minifb`, 1236×1648 scaled 50%, mouse = touch, keys `[`/`]` = light).

### Task 8: Probe binary

**File:** `crates/zarathustra/src/main.rs`.
- Draws a 16-step gray ramp + frame and refreshes Full.
- Event loop on `poll()` over the touch fd. Touch down → 24 px black square (Fast refresh on its rect only). Right/left third tap → swap pattern with a swipe refresh. Top-left corner → exit. Top band left/right → warmth −/+; bottom band left/right → brightness −/+.
- Logs latency (touch timestamp → refresh submit) to stderr.

### Task 9: KUAL packaging + deploy script

**Files:** `dist/kual/zarathustra/{config.xml,menu.json,run.sh}`, `scripts/deploy.sh`.
- `run.sh`: `stop lab126_gui`, `lipc-set-prop com.lab126.powerd preventScreenSaver 1`, run the probe with a log at `/mnt/us/zarathustra/probe.log`, then `preventScreenSaver 0` and `start lab126_gui` (always, via trap).
- `deploy.sh`: build release and copy the binary + extension to the mounted Kindle.

### Task 10: On-device verification

Eject, launch from KUAL → Zarathustra → Probe. Check: the pattern shows, touches draw fast, swipe animation runs, the light bands work, exit restores the Kindle UI. Record measured latency in the commit message.
